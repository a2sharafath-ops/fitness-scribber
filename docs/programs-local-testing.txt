What is available
- Programs replaces Workout Plans. Exercise Library remains separate.
- Six editable starters, coach-created programs, week duplication, session editing.
- Assign to client: select client, Monday start, template week range, weekdays,
  then review the dated sessions and any conflicts before assigning.
- Client-owned copies appear in Training. Open a program to edit its future
  sessions with the existing builder. Changes do not propagate to the template.
- Rep ranges, percentage prescriptions and optional RIR survive assignment,
  copying, persistence and workout logging. Actual reps remain a single number.
- RIR/RPE with a rep range does not invent one exact calculated load. Specify
  the load yourself; explicit percentages still resolve against the client's TM.
- Existing flat plans are retained under Previous workout plans. Conversion is
  one session, preserves the original plan, and requires review for unknown names.

Database integration for a future release
- supabase/schema_program_library.sql is prepared but NOT applied to the live DB.
- Requires the existing schema.sql, schema_program.sql and schema_workouts.sql.
- Adds programs/programAssignments, ownership policies, indexed unique calendar
  dates, a short client-row lock trigger on calendar writes, and assign_program.
- New assignments and their sessions use one transaction; a rejected assignment
  never falls back to independent prescription upserts.
- The setup intentionally fails if existing prescriptions have duplicate
  coach/client/date keys. Review duplicates before applying, never auto-delete.
- Local SQL checks use a temporary PGlite installation outside the project.
  To rerun, set PGLITE_MODULE to its dist/index.js and run:
  node tests/program-sql-check.mjs
- Production migrations/deployment and production concurrency testing remain
  separate release steps. Nothing has been pushed or deployed.

Scope
Assignment creates dated session copies, not booked appointments. Template edits
do not resync copies. Editing a client session updates that calendar session.
Started/completed workouts and past dates are protected during assignment.
The selected template weeks share a weekday mapping by session position;
unselected days remain unplanned/rest days, not completed sessions.
