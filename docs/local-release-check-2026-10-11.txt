DEPENDENCY AUDIT — ACTION BEFORE RELEASE RECOMMENDED
npm audit returned five high-severity package findings (not five independent
application vulnerabilities). No critical findings. Patches are available.
- react-router-dom 7.18.0 / react-router 7.18.0: one shared advisory, fixed in
  7.18.2. The advisory affects unstable RSC APIs. This app uses BrowserRouter in
  a static Vite SPA; no use of those APIs was found. No applicable exploit path
  was demonstrated, but updating to a patched compatible version is recommended.
  https://github.com/advisories/GHSA-qwww-vcr4-c8h2
- postcss 8.5.15: build dependency via Vite; source-map file disclosure findings.
  Current audit marks versions through 8.5.22 affected. Update to a patched version.
  https://github.com/advisories/GHSA-fxqj-rqcc-2cmp
  https://github.com/advisories/GHSA-r28c-9q8g-f849
- nanoid 3.3.15: transitive build dependency via PostCSS; invalid generator size
  can loop indefinitely. Use a patched compatible version (at least 3.3.18).
  https://github.com/advisories/GHSA-28wg-ghj8-5hjv
  https://github.com/advisories/GHSA-2v37-7h3g-55p8
- source-map-js 1.2.1: transitive build dependency via PostCSS; indexed source-map
  offsets can cause denial of service. Patched range begins at 1.2.2.
  https://github.com/advisories/GHSA-68fv-2mgg-jv7q
These build-time packages are not evidence of an exposed browser vulnerability.
Re-run the full checks after patching; do not blindly run audit fix --force.
