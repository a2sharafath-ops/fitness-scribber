How to read this report + calculation limits

Sets count completed working sets from Main Lift, Accessory Lift and Power only. Exclude the entire warm-up block first, then exclude warm-up sets inside eligible blocks. Exercise names never override these exclusions. Direct and assisting roles come from the Exercise Library. Assisting sets are displayed separately, with no automatic fractional weighting. Volume load = completed sets × actual reps × recorded external load in kilograms; only direct assignments receive this value. It describes exercise exposure, not force measured inside a muscle.

Compound exercises contribute to more than one muscle. Muscle totals overlap: do not add them together. No recorded sets does not prove no training. Missing reps or load stay unknown; a known subtotal is labelled partial. Bodyweight work can have zero external load without zero effort. The model cannot infer left/right balance or per-hand load from current records.

Gray regions have no known direct value for the selected metric. Deep groups appear in the list; illustration positions do not imply precise individual muscle measurement. Week boundaries use Monday–Sunday in the client’s configured reporting timezone. This preview uses sample dates and data only.
